# MCP rules
- **Coordinator (SKILL.md):** may use read-only MCP tools to understand a task; cluster/cloud changes go through
  `devops` with an A3 quote.
- **Roles (`agents/*.md`):** for planning, design, coding, reviewing or testing, use the context7 (current library
  docs) and sequentialthinking MCP tools when they are available. If either is missing or fails to connect, continue
  without it and say once which tool was missing.
