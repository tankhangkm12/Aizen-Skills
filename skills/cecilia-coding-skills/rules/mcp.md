# Mandatory MCP Rules
- **Coordinator (this SKILL.md):** uses no MCP tools (rule 1); cluster reads go to discovery, changes to devops.
- **Specialist roles (`agents/*.md`):** for planning, design, coding, reviewing or testing, use the context7 and
  sequentialthinking MCP tools when they are available. If either is not installed or fails to connect, continue
  without it and say once which tool was missing.
